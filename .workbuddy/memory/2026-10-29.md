# 2026-10-29

## 首页「同学们在讨论」社区块为空 —— 已定位并修复

### 根因（后端）
`QuestionServiceImpl.queryHot` 只认 Redis ZSet `hot:questions`，且把结果缓存 5~11 分钟：
1. ZSet 里残留已删问题的 member（2002/2004/2008/2115476820766068738），回表全部落空；
2. 题库 41001~41003 是直接 INSERT 的种子数据，从没走过 publish，压根不在 ZSet；
3. 空结果 `[]` 被缓存成快照 → 首页社区块被「空白锁死」，等很久也不恢复。

### 修复
- `queryHot` 重写：空快照视为未命中；ZSet 优先级不变，有效条目不足时按 DB 热度（like*3+view）补齐并 `addIfAbsent` 写回账本（自愈）；顺手 `ZREM` 掉指向已删/下架问题的脏 member；空结果只压 30 秒防穿透。
- 抽出 `pickHotQuestions / candidatesFromDb / assemble / readHotCache / dbHeat` 私有方法；`assemble` 统一补作者+标签（热榜卡片现在有话题标签）。
- 热度变化（publish / like / unlike）删除 `cache:hot:questions` 快照。
- `queryPage` 的 sort 不传/传空按 new 处理，不再抛「未知排序错误」；修掉 like 里「请勿重复短暂」错别字。

### 前端
- `HomeView` 的 `Promise.all` → `Promise.allSettled`，二手/活动/社区/标签四块各自降级，一块挂不再拖空整页。
- `loadQuestions()` 热榜为空时回退 `questionApi.page({sort:'hot'})`；社区块单独的错误态 + 「重新加载」。
- 话题云改用 computed `topics`：标签接口为空时用问题自带标签兜底，`v-if` 防空标题。
